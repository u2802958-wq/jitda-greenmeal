# 🦉 올빼미 급식 비교소

전국 초·중·고 급식을 **NEIS 교육정보 개방 포털 공개 API**로 불러와,
**날짜 + 학교 2곳**을 골라 급식의 **영양소와 식단 구성을 비교 분석**하는 웹앱입니다.
학생들과 **따라하기 수업**을 할 수 있도록 단계별 코드와 수업 자료가 함께 들어 있습니다.

---

## ⚡ 1분 안에 실행하기

**설치할 것이 하나도 없습니다.** `index.html` 파일을 **두 번 클릭**하면 끝입니다.

- 서버, Node.js, npm, 라이브러리 **전부 필요 없음**
- NEIS 인증키도 **없어도 급식 비교가 됩니다** (학교 검색 결과만 5곳으로 제한)
- 인터넷이 막힌 교실이라면 앱 안의 **🎬 예시 데이터로 먼저 보기** 버튼으로 수업 진행 가능

> 처음 열면 오늘 날짜가 들어갑니다. **방학이나 주말이면 급식 자료가 없습니다.**
> `🔎 급식 있는 날 찾기` 버튼을 누르면 자동으로 급식이 있는 평일을 찾아 줍니다.

---

## 🧩 이 앱이 하는 일

| 기능 | 설명 |
|---|---|
| 전국 학교 검색 | 시도교육청 + 학교 이름으로 초·중·고 검색 |
| 날짜·끼니 선택 | 조식 / 중식 / 석식 선택 |
| 식단 비교 | 요리 목록, 알레르기 번호 18종, 급식 인원, 열량 |
| 영양소 비교 | 10개 항목 막대그래프 + 학교급별 권장 기준선 |
| 식품군 자동 분류 | 요리 이름으로 5개 식품군 분류(누적 막대) |
| 급식 질 점수 | 5개 항목 0~100점 + 레이더 차트 + **중요도 직접 조절** |
| 원산지 비교 | 두 학교가 다르게 적은 품목을 진하게 표시 |
| 자동 분석 코멘트 | 규칙 기반 해설 + 토론 질문 자동 생성 |
| 내보내기 | CSV 저장(엑셀), 인쇄/PDF |

## 📁 폴더 안내

```
급식비교/
├─ index.html          ← 이 파일을 두 번 클릭하면 앱이 열립니다
├─ style.css           ← 꾸미기 담당 (학생은 그대로 사용)
├─ app.js              ← 프로그램 담당 (수업에서 함께 만드는 파일 = 5단계 완성본)
│
├─ steps/              ← 단계별 완성 코드 (뒤처진 학생 복구용 "정답지")
│   ├─ 1단계_app.js     화면 확인 · 오늘 날짜 · 시도 목록
│   ├─ 2단계_app.js     학교 검색 (첫 API 호출)
│   ├─ 3단계_app.js     급식 불러오기 · 파싱 · 식단 카드
│   ├─ 4단계_app.js     영양소 막대그래프 · 식품군 분류
│   └─ 5단계_완성_app.js 점수 · 레이더 차트 · 코멘트 (= 루트 app.js와 동일)
│
├─ data/
│   └─ NEIS_응답_예시.json  ← API가 주는 자료의 실제 모양 (읽기용)
│
├─ docs/               ← 수업 자료 원본 (고쳐서 쓰세요)
│   ├─ 01_교사용_수업지도안.md     5차시 지도안 · 준비물 · 사전 점검
│   ├─ 02_학생용_따라하기_워크북.md  ★ 학생이 보고 따라 하는 핵심 자료
│   ├─ 03_활동지_급식비교분석.md    인쇄용 조사·분석 활동지
│   ├─ 04_NEIS_API_치트시트.md     필드 이름 · 시도 코드 · 알레르기 번호 표
│   ├─ 05_오류해결_트러블슈팅.md    "안 될 때" 증상별 해결법
│   └─ 06_평가루브릭.md            평가 기준표 + 자기·동료 평가지
│
└─ pdf/                ← 위 6개 문서의 인쇄용 PDF (그대로 출력·배부 가능)
```

> 💡 **학생용 워크북(02번)** 은 **25개의 작은 계단**으로 되어 있습니다.
> 계단마다 코드를 붙여넣고 → 저장 → 새로고침 → **화면에서 결과를 눈으로 확인**하는 방식이라,
> 코딩을 한 번도 안 해 본 학생도 매번 성취감을 느끼며 따라올 수 있습니다.

## 🏫 수업에서 쓰는 방법 (요약)

1. 선생님이 이 폴더 전체를 학생 컴퓨터에 복사합니다.
2. 학생은 `docs/02_학생용_따라하기_워크북.md`를 보며 **`app.js`를 단계별로 채워 나갑니다.**
   - `index.html`과 `style.css`는 **처음부터 완성본을 제공**합니다 (타이핑 실수 방지).
   - 학생이 만드는 것은 `app.js` **하나뿐**입니다.
3. 막히면 `steps/N단계_app.js`의 내용을 자기 `app.js`에 **덮어쓰기**하고 다음 단계로 갑니다.
   → **한 명도 낙오하지 않습니다.**
4. 앱이 완성되면 `docs/03_활동지_급식비교분석.md`로 실제 데이터를 분석·토론합니다.

## ⚠️ 반드시 알려 주어야 할 두 가지

**① 점수는 공식 지표가 아닙니다.**
이 앱의 급식 점수는 **수업에서 우리가 직접 만든 기준**입니다.
학교마다 학생 수, 예산, 지역 식재료 사정, 학교급이 다르므로
점수가 낮다고 급식이 나쁜 것이 아닙니다. **학교 간 우열을 가리는 도구로 쓰지 않습니다.**

**② 영양 기준값은 확인이 필요합니다.**
`app.js`의 `STANDARD` 상수는 학교급식법 시행규칙 별표 3 「학교급식의 영양관리기준」을
참고한 **수업용 값**입니다. 고시가 개정될 수 있으니 수업 전 최신 값을 확인하고
그 숫자만 고쳐 주세요. (이 확인 과정 자체가 좋은 수업 소재입니다.)

## 🔑 NEIS 인증키 (선택)

| | 키 없음 | 키 있음 |
|---|---|---|
| 급식 조회 | ✅ 정상 | ✅ 정상 |
| 학교 검색 | ⚠️ **5곳만** 표시 | ✅ 100곳까지 |
| 하루 사용량 | 적음 | 넉넉함 |

발급: <https://open.neis.go.kr> → 회원가입 → 인증키 신청 → **즉시 발급, 무료**
앱의 `🔑 NEIS 인증키 넣기`를 열어 붙여넣으면 그 컴퓨터에만 저장됩니다(서버로 보내지 않음).

> 학급에서 30명이 동시에 키 없이 사용하면 IP 기준 사용량 제한에 걸릴 수 있습니다.
> **선생님 키 하나를 학생들에게 공유**하거나, 학생별로 각자 발급받게 하는 것을 권합니다.
