# 📖 0장. 준비운동

## 먼저 알아야 할 낱말 (딱 12개만!)

지금 다 외우지 마세요. **모르는 말이 나오면 여기로 돌아와서 찾아보면 됩니다.**

| 낱말 | 아주 쉬운 뜻 | 예 |
|---|---|---|
| **코드** | 컴퓨터에게 시키는 말 | `$('#date').value = '2026-07-08';` |
| **파일** | 코드를 적어 두는 종이 | `app.js` |
| **함수** | 이름을 붙여 둔 **기계** | `todayISO()` 를 부르면 오늘 날짜가 나옴 |
| **부른다(호출)** | 그 기계를 작동시킨다 | `todayISO()` 처럼 뒤에 `()` 를 붙임 |
| **변수** | 값을 담아 두는 **상자** | `const 나이 = 15;` |
| **문자열** | 글자 덩어리. 따옴표로 감쌈 | `'안녕'` |
| **배열** | 여러 개를 순서대로 담은 줄 | `['사과', '우유', '밥']` |
| **객체** | 이름표를 붙여 담은 상자 | `{ 이름: '홍길동', 나이: 15 }` |
| **세미콜론 `;`** | 한 문장의 마침표 | 줄 끝에 붙임 |
| **중괄호 `{ }`** | 여러 줄을 하나로 묶는 보자기 | `function 이름() { 여기 }` |
| **주석** | 컴퓨터가 **무시하는** 메모 | `// 이건 설명이에요` |
| **콘솔(Console)** | 컴퓨터의 **속마음 창**. F12로 엶 | 결과를 몰래 확인할 때 |

> ### 🔰 따옴표가 3가지예요!
> | 기호 | 이름 | 언제 쓰나 |
> |---|---|---|
> | `'안녕'` | 작은따옴표 | 보통 글자 |
> | `"안녕"` | 큰따옴표 | 보통 글자 (작은따옴표와 같음) |
> | `` `안녕 ${이름}` `` | **백틱** | 글자 **사이에 값을 끼워 넣을 때** |
>
> **백틱은 키보드 왼쪽 위, 숫자 1 왼쪽에 있는 `~` 키를 그냥 누르면 나옵니다.**
> 백틱 안에서 `${ }` 를 쓰면 그 자리에 값이 들어갑니다.
> ```js
> const 이름 = '민서';
> console.log(`안녕 ${이름}!`);   // → 안녕 민서!
> ```

## ✅ 미션 1. 화면에 인사말 띄우기

**무엇을 하나요?** 화면에 내가 쓴 글씨가 나타나게 합니다.

### ✍️ 1) **①번 도구 칸**에 붙여넣기

```js
/* 화면에서 무언가를 찾아 주는 도구 (앞으로 계속 씁니다!) */
const $  = (sel, root = document) => root.querySelector(sel);
const $$ = (sel, root = document) => Array.from(root.querySelectorAll(sel));

/* 화면 위쪽 알림줄에 글씨를 띄우는 기계 */
function setStatus(html, kind = '') {
  const box = $('#status');
  if (!html) { box.hidden = true; box.innerHTML = ''; return; }
  box.hidden = false;
  box.className = 'status ' + kind;
  box.innerHTML = html;
}
```

### ✍️ 2) **⑧번 시작 칸**의 `★★★` 표시 아래에 붙여넣기

```js
  setStatus('안녕하세요! 제가 만드는 급식 앱입니다. 🦉');
```

**💾 Ctrl+S → 🔄 F5**

**👀 확인!**
화면 가운데쯤에 **"안녕하세요! 제가 만드는 급식 앱입니다. 🦉"** 라는 상자가 나타납니다.

- [ ] **성공!** 내가 쓴 글씨가 화면에 떴어요! 🎉

**🎨 재미로 해보기** — 따옴표 안의 글씨를 **내 이름**으로 바꿔 보세요.
`setStatus('민서가 만드는 급식 앱! 🦉');` → 저장 → F5

> ### 🔰 코드 뜯어보기
>
> **① `$` 는 뭐예요?**
> 화면에서 물건을 찾아오는 **집게**라고 생각하세요.
> 원래 이름은 `document.querySelector` 인데 너무 길어서 `$` 로 줄였습니다.
> ```
> $('#status')  →  "id가 status 인 것을 찾아와"
> ```
> - `#` 로 시작하면 → **id**를 찾음 (id는 반에 한 명뿐인 이름표)
> - `.` 로 시작하면 → **class**를 찾음 (class는 여러 명이 같이 다는 이름표)
>
> `index.html` 파일 안에 `<p class="status" id="status">` 라고 적혀 있어서 찾을 수 있는 거예요.
>
> **② `function setStatus(html, kind = '') {` 는요?**
> `setStatus` 라는 **기계를 만든다**는 뜻입니다.
> 괄호 안의 `html`, `kind` 는 **기계에 넣는 재료**예요.
> `kind = ''` 는 "재료를 안 넣으면 빈 글자로 하겠다"는 뜻입니다.
>
> **③ `box.innerHTML = html;`**
> `innerHTML` 은 **"그 상자 안의 내용"** 이라는 뜻이에요.
> 여기에 글자를 넣으면 화면에 그대로 보입니다.
>
> **④ `if (!html) { ... return; }`**
> `if` 는 **만약에**, `!` 는 **아니라면** 이라는 뜻이에요.
> "만약 글자가 없으면 → 상자를 숨기고 → `return`(여기서 끝!)"

## ✅ 미션 2. 오늘 날짜 자동으로 넣기

**무엇을 하나요?** 날짜 칸에 오늘 날짜가 저절로 들어가게 합니다.

### ✍️ 1) **①번 도구 칸** 맨 아래에 붙여넣기

```js
/* 오늘 날짜를 2026-07-08 모양으로 만들어 주는 기계 */
function todayISO() {
  const d = new Date();
  const p = n => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}
```

### ✍️ 2) **⑧번 시작 칸**의 `★★★` 아래에 한 줄 추가

```js
  $('#date').value = todayISO();
```

**💾 Ctrl+S → 🔄 F5**

**👀 확인!**
화면 왼쪽 위 **날짜 칸에 오늘 날짜**가 들어가 있습니다.

- [ ] **성공!** 날짜가 자동으로 채워졌어요.

> ### 🔰 코드 뜯어보기
>
> **`new Date()`** → 지금 이 순간의 날짜와 시각을 가져옵니다.
>
> **`d.getMonth() + 1`** ← 여기 주의!
> 컴퓨터는 달(月)을 **0부터** 셉니다. 1월이 0, 8월이 7이에요.
> 그래서 **+1** 을 해 줘야 우리가 아는 달이 됩니다. (많은 사람이 틀리는 부분!)
>
> **`padStart(2, '0')`** → 글자를 2칸으로 만들고 빈 곳은 `0`으로 채웁니다.
> `8` → `08` 이 됩니다. (날짜는 `2026-7-8`이 아니라 `2026-07-08` 이어야 하니까요)
>
> **`.value`** → 입력칸에 **쓰여 있는 값**을 뜻합니다. 여기에 값을 넣으면 칸이 채워져요.
>
> **`return`** → 기계가 만들어 낸 결과를 **밖으로 내보내는** 것입니다.

> ### 🔰 코드 뜯어보기
>
> **`const SIDO_LIST = [ ... ];`**
> `const` 는 **바뀌지 않는 상자**를 만든다는 뜻. `[ ]` 는 **배열**(줄 세우기)입니다.
> 안에 또 `[ ]` 가 있죠? `['B10', '서울특별시교육청']` 처럼 **짝**으로 묶어 둔 거예요.
>
> **`$$('.sido')`**
> `$$` 는 **여러 개**를 찾는 집게였죠. `.sido` 는 class가 sido인 것 → 학교 A와 B의 목록 **2개**를 찾습니다.
>
> **`.forEach(sel => { ... })`**
> "찾은 것 **하나하나마다** 이걸 해라" 라는 뜻이에요. 2개니까 2번 실행됩니다.
>
> **`.map()` 과 `.join('')` — 앞으로 계속 나오니 여기서 확실히!**
> ```
> [['B10','서울특별시교육청'], ['C10','부산광역시교육청']]
>            ↓ .map()  = 하나하나를 다른 모양으로 바꾸기
> ['<option value="B10">서울특별시</option>', '<option value="C10">부산광역시</option>']
>            ↓ .join('')  = 전부 이어 붙여 하나의 긴 글자로
> '<option value="B10">서울특별시</option><option value="C10">부산광역시</option>'
> ```
> 이렇게 만든 긴 글자를 `innerHTML` 에 넣으면 → 화면에 목록이 생깁니다!
>
> **`name.replace('교육청', '')`** → `'서울특별시교육청'` 에서 `'교육청'` 을 지워 `'서울특별시'` 로 만듭니다.

```js
/* 인터넷에서 온 글자를 화면에 안전하게 넣기 위한 기계 */
function esc(s) {
  return String(s ?? '').replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
}
```

### ✍️ 2) **③번 NEIS 부르기 칸**에 붙여넣기

```js
const API_BASE = 'https://open.neis.go.kr/hub/';

/* 저장해 둔 인증키 꺼내기 (없으면 빈 글자) */
function getKey() {
  return localStorage.getItem('neisKey') || '';
}

/* NEIS에 물어보고 답을 받아오는 기계 */
async function callNeis(endpoint, params) {
  const q = new URLSearchParams({ Type: 'json', pIndex: 1, pSize: 100, ...params });
  const key = getKey();
  if (key) q.set('KEY', key);

  const url = API_BASE + endpoint + '?' + q.toString();
  console.log('부르는 주소 👉', url);

  let res;
  try {
    res = await fetch(url);                 // ← 인터넷에서 받아오기!
  } catch (e) {
    throw new Error('NETWORK');
  }
  if (!res.ok) throw new Error('HTTP ' + res.status);

  const data = await res.json();            // ← 글자를 자료로 바꾸기

  // 자료가 하나도 없으면 NEIS는 { RESULT: ... } 만 보냅니다
  if (data.RESULT) {
    if (data.RESULT.CODE === 'INFO-200') return [];
    throw new Error(data.RESULT.CODE + ' : ' + data.RESULT.MESSAGE);
  }

  const body = data[endpoint];
  if (!body) return [];

  const head = body[0]?.head?.[1]?.RESULT;
  if (head && head.CODE !== 'INFO-000') throw new Error(head.CODE + ' : ' + head.MESSAGE);

  const rows = body[1]?.row || [];
  rows.totalCount = body[0]?.head?.[0]?.list_total_count ?? rows.length;
  return rows;
}

/* 학교 이름으로 찾기 */
function searchSchools(name, sido) {
  const params = { SCHUL_NM: name };
  if (sido) params.ATPT_OFCDC_SC_CODE = sido;
  return callNeis('schoolInfo', params);
}

/* 문제가 생겼을 때 알아들을 수 있는 말로 바꿔 주기 */
function showError(e) {
  const msg = String(e.message || e);
  if (msg === 'NETWORK') {
    setStatus(`<b>NEIS에 연결하지 못했습니다.</b>
      <ol>
        <li>인터넷이 연결되어 있는지 확인하세요.</li>
        <li>학교 방화벽이 막을 수 있습니다. 휴대폰 핫스팟으로 시도해 보세요.</li>
        <li>그래도 안 되면 <b>🎬 예시 데이터로 먼저 보기</b> 버튼을 누르면 수업을 이어갈 수 있습니다.</li>
      </ol>`, 'error');
    return;
  }
  if (msg.includes('INFO-300')) {
    setStatus('<b>인증키가 올바르지 않습니다.</b> 🔑 상자를 열어 키를 다시 붙여넣거나, 키를 지우고(키 없이) 사용하세요.', 'error');
    return;
  }
  if (msg.includes('ERROR-337')) {
    setStatus('<b>오늘 사용할 수 있는 횟수를 다 썼습니다.</b> 인증키를 등록하면 훨씬 많이 쓸 수 있습니다.', 'error');
    return;
  }
  setStatus(`문제가 생겼습니다: <code>${esc(msg)}</code>`, 'error');
}
```

>
> **① `async` 와 `await` — 분식집 이야기 🍜**
> ```
> await 없으면:  라면 주문! → 곧바로 "맛있다!" 라고 말함 → 아직 라면이 안 나왔는데?? 😵
> await 있으면:  라면 주문! → 나올 때까지 기다림 → 받고 나서 "맛있다!" 😋
> ```
> 인터넷은 느립니다(0.5초쯤). `await` 를 안 쓰면 자료가 오기 전에 다음 줄로 넘어가 버려요.
> **`await` 를 쓰는 기계 앞에는 반드시 `async` 를 붙여야 합니다.**
>
> **② `fetch(url)`**
> 진짜로 인터넷에서 받아오는 명령입니다. 딱 한 줄이에요!
>
> **③ `await res.json()`**
> 받아온 **글자**를 우리가 쓸 수 있는 **자료(객체·배열)** 로 바꿉니다.
>
> **④ 껍데기가 두 겹인 이유**
> NEIS의 답은 이렇게 생겼어요.
> ```
> { "schoolInfo": [ { "head": [...] },     ← 0번: 몇 개 찾았는지 알려 주는 칸
>                   { "row":  [...] } ] }  ← 1번: 진짜 자료가 든 칸
> ```
> 그래서 `body[1].row` 로 들어가야 학교 목록이 나옵니다. **0번부터 세는 것**을 잊지 마세요!
>
> **⑤ `?.` 는 안전벨트**
> `body[1]?.row` → "만약 `body[1]`이 없어도 오류 내지 말고 그냥 넘어가"
>
> **⑥ `try` / `catch`**
> - `try` → 일단 해 봐
> - `catch` → 잘못되면 여기로 와 (**프로그램이 죽지 않게!**)
>
> **⑦ `btn.closest('.picker')`**
> "내가 눌린 버튼을 **감싸고 있는** 상자를 찾아라". 학교 A 버튼을 누르면 A 상자를 찾습니다.
>
> **⑧ `console.log('찾은 학교 👉', rows)`**
> **콘솔(속마음 창)에 몰래 찍어 보는 것**입니다. 화면에는 안 보이고 F12에서만 보여요.
> 코딩할 때 **가장 많이 쓰는 확인 방법**이니 꼭 기억하세요!

```js
  const sidoSel = $('.sido', box);

      }
    } catch (e) {
```

```js
/* '<br/>' 로 이어진 글자를 배열로 쪼개기 */
function splitBr(text) {
  return String(text || '')
    .split(/<br\s*\/?>/i)      // <br>, <br/>, <BR /> 전부 처리
    .map(s => s.trim())        // 앞뒤 공백 지우기
    .filter(Boolean);          // 빈 칸 버리기
}

/* "순두부찌개 (1.5.9.13)" → { name:'순두부찌개', allergens:[1,5,9,13] } */
function parseDishes(ddish) {
  return splitBr(ddish).map(raw => {
    let s = raw.replace(/\*/g, '').trim();        // 맨 앞의 * 지우기

    let allergens = [];
    const m = s.match(/\(([\d.\s]+)\)\s*$/);      // 맨 끝의 (숫자.숫자) 찾기
    if (m) {
      allergens = m[1].split('.').map(v => parseInt(v.trim(), 10)).filter(Number.isFinite);
      s = s.slice(0, m.index).trim();             // 괄호 앞까지만 남기기
    }
    // (자), (완), (과) 같은 학교별 표시도 지우기
    const name = s.replace(/\((자|완|과|꿀함유|[^)]{1,6})\)\s*$/, '').trim() || s;

    return { name, allergens };
  });
}

/* "697.5 Kcal" → 697.5 (숫자만 뽑기) */
function parseCalorie(cal) {
  const m = String(cal || '').match(/[\d.]+/);
  return m ? parseFloat(m[0]) : null;
}

/* "탄수화물(g) : 87.3" → { 탄수화물: { value:87.3, unit:'g' } } */
function parseNutrients(ntr) {
  const out = {};
  for (const line of splitBr(ntr)) {
    const m = line.match(/^(.+?)\s*\(([^)]*)\)\s*:\s*([\d.]+)/);
    if (!m) continue;
    const name = m[1].trim();                        // 비타민A
    out[name] = { value: parseFloat(m[3]), unit: m[2].trim() };
  }
  return out;
}

/* "쌀 : 국내산" → { 쌀: '국내산' } */
function parseOrigin(orplc) {
  const out = {};
  for (const line of splitBr(orplc)) {
    const i = line.indexOf(':');
    if (i < 0) continue;
    const k = line.slice(0, i).trim();
    const v = line.slice(i + 1).trim();
    if (k && v) out[k] = v;
  }
  return out;
}
```

> ### 🔰 정규식(`/…/`)이 뭐예요?
> **"이런 모양의 글자를 찾아 줘"** 라고 말하는 방법이에요. 지금은 이 4개만 알면 충분합니다.
>
> | 기호 | 뜻 | 예 |
> |---|---|---|
> | `\d` | 숫자 하나 | `\d\d` → `13` |
> | `+` | 앞의 것이 1개 이상 | `\d+` → `1358` |
> | `$` | 글자의 **맨 끝** | `\(\d+\)$` → 끝에 있는 `(13)` |
> | `\.` | 진짜 점(.) | `1.5` 의 점 |
>
> `/\(([\d.\s]+)\)\s*$/` 는 → **"맨 끝에 있는, 숫자와 점으로만 된 괄호"** 를 찾으라는 뜻!
>
> 😌 **지금 다 이해 못 해도 괜찮아요.** 그대로 써도 잘 작동합니다.
> 나중에 필요할 때 다시 보면 됩니다!
>
> **`.split()` / `.trim()` / `.filter()`**
> | 이름 | 하는 일 |
> |---|---|
> | `split('구분자')` | 구분자를 기준으로 **자르기** |
> | `trim()` | 앞뒤 **공백 지우기** |
> | `filter(Boolean)` | **빈 것 버리기** |

> ### 🔰 코드 뜯어보기
>
> **① `Promise.all` — 두 배 빠르게! ⚡**
> ```
> 하나씩:      A학교 부르기(1초) → 끝나면 B학교 부르기(1초)  = 2초

> ```
> **② `const [rowsA, rowsB] = await Promise.all([...])`**
> 결과 2개를 한 번에 두 상자에 나눠 담는 방법이에요. (구조 분해라고 불러요)

> `find` 는 **조건에 맞는 첫 번째 것 하나**를 찾아 줍니다.
> `===` 는 **"똑같다"** 는 뜻이에요. (`=` 은 "넣는다", `===` 은 "같다" — 다릅니다!)
>
> **④ `$('#result').hidden = false;`**
> 결과 영역은 원래 **숨겨져** 있었어요. 이제 보이게 하는 겁니다.
>
> **⑤ `scrollIntoView`**
> 화면을 결과가 있는 곳으로 **부드럽게 스크롤**해 줍니다.
>
> **⑥ `card(A, 'a') + card(B, 'b')`**
> 카드 만드는 기계를 **두 번 불러서** 이어 붙입니다. A는 파란색, B는 주황색이에요.

> ### 🔰 `flatMap` 과 `Set` 이 뭐죠?
> ```
> R.dishes.flatMap(d => d.allergens)
>   요리마다 [6], [1,5,9,13], [5,6,13] … 을 꺼내서 → [6,1,5,9,13,5,6,13,…] 로 납작하게 펼침
>            ↓ new Set(…)  = 중복 없애기
>   [6,1,5,9,13]
>            ↓ .sort((a,b) => a-b)  = 작은 수부터 줄 세우기
>   [1,5,6,9,13]
> ```
> `flat` 은 **납작하게**라는 뜻이에요. 배열 안의 배열을 하나로 펼쳐 줍니다.

> ### 🔰 코드 뜯어보기
> **`title="…"`** → 마우스를 올렸을 때 뜨는 **말풍선**을 만드는 HTML 표시입니다.

## ⭐ 미션 15. 영양소 막대그래프 그리기

### 💡 먼저 원리부터 (초등 산수예요!)

```
                     내 값
    막대 길이(%) = ─────────── × 100
                   가장 큰 값
```

**예제** — 칼슘: A학교 265.8mg, B학교 154.3mg → 가장 큰 값은 **265.8**
- A: 265.8 ÷ 265.8 × 100 = **100%**
- B: 154.3 ÷ 265.8 × 100 = **58%**

이 숫자를 CSS의 `width`(너비)에 넣으면 **그게 바로 막대그래프**입니다! 🎉

```html
<div style="width:100%">A학교</div>     ← 긴 막대
<div style="width:58%">B학교</div>      ← 짧은 막대
```

### ✏️ 직접 계산해 보기
철분이 A학교 2.8mg, B학교 4.5mg 일 때
가장 큰 값 = ______ → A = ______% → B = ______%

```js
function renderLegend(A, B) {
  const html = `

    <span><i style="background:var(--b)"></i>${esc(B.school.SCHUL_NM)}</span>`;

/* 막대 한 줄 만들기 (A와 B를 위아래로 나란히) */
function barRow(label, sub, aVal, bVal, max, unit, goal) {
  const bar = (v, cls) => {
    if (v == null) return `<div class="bar-track"><div class="bar-fill ${cls} low" style="width:0%">자료 없음</div></div>`;
    const pct = max > 0 ? clamp((v / max) * 100, 0, 100) : 0;      // ★ 여기가 계산!
    const text = `${round1(v)}${unit || ''}`;
    return `<div class="bar-track">
      <div class="bar-fill ${cls}${pct < 30 ? ' low' : ''}" style="width:${pct.toFixed(1)}%">${text}</div>
    </div>`;
  };
  /* 권장 기준값 자리에 세로선 하나 세우기 */
  const goalMark = (goal != null && max > 0 && goal <= max)
    ? `<div class="bar-goal" style="left:${((goal / max) * 100).toFixed(1)}%"></div>` : '';

  return `<div class="bar-item">
    <div class="bar-label">${esc(label)}${sub ? `<small>${esc(sub)}</small>` : ''}</div>
    <div class="bar-track-set">${goalMark}${bar(aVal, 'a')}${bar(bVal, 'b')}</div>
  </div>`;
}

/* 영양소 막대 그리기 */
function renderNutriBars(A, B) {
  const rows = NUTRI_ORDER.map(name => {
    const a = A.nutri[name]?.value ?? null;
    const b = B.nutri[name]?.value ?? null;
    if (a == null && b == null) return '';            // 둘 다 없으면 줄을 안 만듦

    const unit = A.nutri[name]?.unit || B.nutri[name]?.unit || '';
    const gA = A.std[name], gB = B.std[name];
    /* 두 학교의 기준이 같을 때만 기준선을 그립니다 */
    const goal = (gA != null && gA === gB) ? gA : null;

    const max = Math.max(a ?? 0, b ?? 0, goal ?? 0) * 1.12 || 1;
    const sub = (gA != null || gB != null)
      ? `기준 A ${gA ?? '–'} / B ${gB ?? '–'}`
      : '';
    return barRow(`${name}${unit ? ` (${unit})` : ''}`, sub, a, b, max, '', goal);
  }).join('');

  $('#nutriBars').innerHTML = rows || '<p>영양 정보가 제공되지 않았습니다.</p>';

  $('#nutriHint').innerHTML = A.levelKey === B.levelKey
    ? `막대 길이는 두 학교 중 큰 값에 맞춰 그렸습니다.
       세로선(<b>기준</b>)은 <b>${esc(STANDARD[A.levelKey].label)}</b> 1인 1회 참고 기준값입니다.`
    : `막대 길이는 두 학교 중 큰 값에 맞춰 그렸습니다.

}
```

> 그래서 **더 긴 낱말**을 믿습니다.
> `배추`(2글자) > `배`(1글자) → **채소류** ✅
>
> ```js
> if (name.includes(w) && w.length > bestLen) { bestLen = w.length; best = g; }
>                         └── 지금까지 찾은 것보다 더 길면 → 바꾼다
> ```
>
> **`for (const g of FOOD_GROUPS)`** → 식품군 5개를 하나씩 꺼내 봅니다.
> **`name.includes(w)`** → "이름 안에 이 낱말이 들어 있니?" (있으면 true)

```js
/* ① 열량 적정성 — 권장 열량에 가까울수록 100점 (많아도 감점!) */
function scoreEnergy(R) {
  if (R.kcal == null || !R.std.에너지) return null;
  const ratio = R.kcal / R.std.에너지;                 // 1.0 이면 딱 맞음
  return clamp(100 - Math.abs(ratio - 1) * 250, 0, 100);
}

/* ② 단백질 충분도 — 권장 단백질을 채우면 100점 */
function scoreProtein(R) {
  const p = R.nutri['단백질'];
  if (!p || !R.std.단백질) return null;
  return clamp((p.value / R.std.단백질) * 100, 0, 100);
}

/* ③ 식단 다양성 — 식품군 수(70%) + 요리 수(30%) */
function scoreVariety(R) {
  if (!R.dishes.length) return null;
  return clamp((R.groupsCovered / 5) * 70 + (Math.min(R.dishes.length, 7) / 7) * 30, 0, 100);
}

/* ④ 미량영양소 — 칼슘·철분·비타민A·비타민C 달성률의 평균 */
function scoreMicro(R) {
  const rates = ['칼슘', '철분', '비타민A', '비타민C']
    .filter(k => R.nutri[k] && R.std[k])
    .map(k => clamp((R.nutri[k].value / R.std[k]) * 100, 0, 100));
  return rates.length ? rates.reduce((a, b) => a + b, 0) / rates.length : null;
}

/* ⑤ 가공·튀김 절제 — 가공/튀김 비율이 낮을수록 100점 */
function scoreFresh(R) {
  if (!R.dishes.length) return null;
  return clamp(100 - (R.processedCnt / R.dishes.length) * 200, 0, 100);
}

/* 점수 5개를 중요도로 합쳐 총점 내기 (자료 없는 항목은 빼고 계산) */
function totalScore(scores) {
  let sum = 0, w = 0;
  for (const ax of AXES) {
    const v = scores[ax.key];
    if (v == null) continue;
    sum += v * WEIGHTS[ax.key];
    w += WEIGHTS[ax.key];
  }
  return w ? sum / w : null;
}
```

> ```js

> - `2π ÷ 5` = 축 5개를 **똑같은 간격**(72°씩)으로 벌리기

```js
/* 결과를 CSV 파일로 저장 */
function downloadCsv() {
  if (!CURRENT) return;
  const { A, B } = CURRENT;
  const q = v => `"${String(v ?? '').replace(/"/g, '""')}"`;
  const lines = [];

  lines.push(['구분', A.school.SCHUL_NM, B.school.SCHUL_NM].map(q).join(','));

  lines.push(['요리 수', A.dishes.length, B.dishes.length].map(q).join(','));
  lines.push(['식품군 수(5)', A.groupsCovered, B.groupsCovered].map(q).join(','));
  lines.push(['가공·튀김 요리 수', A.processedCnt, B.processedCnt].map(q).join(','));
  lines.push(['급식 인원', A.servings, B.servings].map(q).join(','));

  lines.push('');
  lines.push(['[영양소]', '', ''].map(q).join(','));
  for (const n of NUTRI_ORDER) {
    const a = A.nutri[n], b = B.nutri[n];
    if (!a && !b) continue;
    lines.push([`${n}(${a?.unit || b?.unit || ''})`, a?.value ?? '', b?.value ?? ''].map(q).join(','));
  }

  lines.push('');
  lines.push(['[항목 점수]', '', '중요도(%)'].map(q).join(','));
  for (const ax of AXES) {
    lines.push([ax.label,
      A.scores[ax.key] == null ? '' : round1(A.scores[ax.key]),
      B.scores[ax.key] == null ? '' : round1(B.scores[ax.key]),
      WEIGHTS[ax.key]].map(q).join(','));
  }
  const tA = totalScore(A.scores), tB = totalScore(B.scores);
  lines.push(['총점', tA == null ? '' : round1(tA), tB == null ? '' : round1(tB)].map(q).join(','));

  /* 맨 앞에 특별한 표시를 붙이면 엑셀에서 한글이 안 깨집니다 */
  const blob = new Blob(['﻿' + lines.join('\r\n')], { type: 'text/csv;charset=utf-8' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `급식비교_${A.school.SCHUL_NM}_${B.school.SCHUL_NM}_${A.date}.csv`;
  a.click();
  URL.revokeObjectURL(a.href);
}
```

```js
async function findRecent() {
  const A = PICKED.A, B = PICKED.B;
  if (!A || !B) { setStatus('먼저 학교 A와 B를 골라 주세요.', 'warn'); return; }

  let checked = 0;
  try {
    for (let back = 0; back <= 30 && checked < 15; back++) {
      const d = new Date(start);
      d.setDate(d.getDate() - back);
      if (d.getDay() === 0 || d.getDay() === 6) continue;      // 토·일은 건너뛰기
      checked++;

      const p = n => String(n).padStart(2, '0');
      const ymd = `${d.getFullYear()}${p(d.getMonth() + 1)}${p(d.getDate())}`;
      setStatus(`${fromYmd(ymd)} 확인 중… (${checked}번째)`, 'loading');

      const [ra, rb] = await Promise.all([fetchMeal(A, ymd), fetchMeal(B, ymd)]);
      const ok = ra.some(r => r.MMEAL_SC_CODE === type) && rb.some(r => r.MMEAL_SC_CODE === type);
      if (ok) {
        $('#date').value = fromYmd(ymd);
        setStatus(`두 학교 모두 급식이 있는 <b>${fromYmd(ymd)}</b>을(를) 찾았습니다. 이제 비교합니다.`);
        await compare();
        return;
      }
    }
    setStatus('최근 15번의 평일에서는 두 학교가 함께 급식한 날을 찾지 못했습니다. 날짜를 학기 중으로 바꿔 보세요.', 'warn');
  } catch (e) {
    showError(e);
  } finally {
    $('#recentBtn').disabled = false;
  }
}
```

## 📖 배운 낱말 정리

| 낱말 | 뜻 | 어디서 썼나 |
|---|---|---|
| **API** | 프로그램끼리 자료를 주고받는 약속 | NEIS에서 급식 받아오기 |
| **JSON** | 자료를 적는 정해진 모양 | NEIS가 준 답 |
| **fetch** | 인터넷에서 자료 받아오기 | `callNeis` |
| **async / await** | 오래 걸리는 일을 기다리기 | 급식 불러오기 |
| **파싱(parsing)** | 긴 글자를 쓸 수 있는 자료로 쪼개기 | `parseDishes` |
| **정규식** | "이런 모양의 글자를 찾아줘" | 알레르기 번호 떼기 |
| **정규화** | 서로 다른 크기를 비교하게 맞추기 | 막대 길이(%) |
| **가중치** | 무엇을 더 중요하게 볼지 정하는 무게 | 총점 계산 |
| **규칙 기반 분류** | 사람이 정한 규칙으로 나누기 | 식품군 분류 |
| **데이터 시각화** | 숫자를 그림으로 보여 주기 | 막대·거미줄 차트 |
