# 📗 NEIS Open API 치트시트

> 포털: <https://open.neis.go.kr> · 이 문서의 내용은 실제 응답을 확인해 정리한 것입니다.

---

## 1. 기본 주소 만들기

```
https://open.neis.go.kr/hub/{서비스이름}?KEY={인증키}&Type=json&pIndex=1&pSize=100&{조건들}
```

| 공통 조건 | 뜻 | 비고 |
|---|---|---|
| `KEY` | 인증키 | **없어도 됨**(응답 5행 제한) |
| `Type` | 응답 형식 | `json` 권장 (`xml`도 가능) |
| `pIndex` | 몇 번째 쪽 | 1부터 |
| `pSize` | 한 쪽에 몇 줄 | 최대 1000 / **키 없으면 5로 제한** |

### 🔑 인증키 있음 / 없음 차이 (직접 확인한 결과)

| | 키 없음 | 키 있음 |
|---|---|---|
| 한 번에 받는 줄 수 | **최대 5줄** | `pSize` 만큼 (최대 1000) |
| `list_total_count` | 전체 개수는 정상 표시 | 정상 |
| 급식 조회(하루, 한 학교) | ✅ 문제 없음 (보통 1~3줄) | ✅ |
| 학교 검색 | ⚠️ 5곳만 보임 | ✅ |
| 하루 사용량 | 적음 | 넉넉함 |

> 즉 **급식 비교는 키 없이도 완전히 동작**하고, 아쉬운 건 **학교 검색**뿐입니다.

## 2. 서비스 ①  학교기본정보 `schoolInfo`

**용도** 학교 이름으로 검색해 `ATPT_OFCDC_SC_CODE`(교육청 코드)와 `SD_SCHUL_CODE`(학교 코드)를 얻습니다.
급식을 조회하려면 이 두 코드가 **반드시** 필요합니다.

### 요청 조건
| 조건 | 뜻 | 예 |
|---|---|---|
| `SCHUL_NM` | 학교 이름 | `창원고` — **부분 일치됩니다** |
| `ATPT_OFCDC_SC_CODE` | 시도교육청 코드 | `S10` (생략하면 전국) |
| `SCHUL_KND_SC_NM` | 학교 종류 | `초등학교` / `중학교` / `고등학교` |
| `LCTN_SC_NM` | 소재지 | `경상남도` |
| `FOND_SC_NM` | 설립 구분 | `공립` / `사립` |

### 주요 응답 필드
| 필드 | 뜻 | 예 |
|---|---|---|
| `ATPT_OFCDC_SC_CODE` | 교육청 코드 ⭐ | `S10` |
| `ATPT_OFCDC_SC_NM` | 교육청 이름 | `경상남도교육청` |
| `SD_SCHUL_CODE` | 학교 코드 ⭐ | `9010114` |
| `SCHUL_NM` | 학교 이름 | `창원고등학교` |
| `SCHUL_KND_SC_NM` | 학교급 | `고등학교` |
| `LCTN_SC_NM` | 소재지 | `경상남도` |
| `FOND_SC_NM` | 설립 | `공립` |
| `COEDU_SC_NM` | 남녀공학 구분 | `남` / `여` / `남여공학` |
| `ORG_RDNMA` | 도로명 주소 | |
| `ORG_TELNO` | 전화번호 | |
| `HMPG_ADRES` | 홈페이지 | |
| `FOND_YMD` | 설립일 | `19790301` |

### 예시
```
https://open.neis.go.kr/hub/schoolInfo?Type=json&pSize=5&SCHUL_NM=창원고등학교
```

> 🔎 부분 일치 예: `SCHUL_NM=과학고` → 전국 84곳이 검색됩니다.

## 3. 서비스 ②  급식식단정보 `mealServiceDietInfo`

### 요청 조건
| 조건 | 필수 | 뜻 | 예 |
|---|---|---|---|
| `ATPT_OFCDC_SC_CODE` | ✅ | 교육청 코드 | `S10` |
| `SD_SCHUL_CODE` | ✅ | 학교 코드 | `9010114` |
| `MLSV_YMD` | | 급식 날짜 (하루) | `20260708` |
| `MLSV_FROM_YMD` | | 시작일 (기간 조회) | `20260701` |
| `MLSV_TO_YMD` | | 종료일 (기간 조회) | `20260731` |
| `MMEAL_SC_CODE` | | 끼니 | `1`조식 `2`중식 `3`석식 |

> **하루 조회**는 `MLSV_YMD` 하나만, **기간 조회**는 `MLSV_FROM_YMD` + `MLSV_TO_YMD` 를 씁니다.
> 기간 조회 시 줄 수가 많아지므로 **인증키가 필요**합니다(키 없으면 5줄에서 잘림).

### 주요 응답 필드
| 필드 | 뜻 | 실제 값 예시 |
|---|---|---|
| `SCHUL_NM` | 학교 이름 | `경기초등학교` |
| `MLSV_YMD` | 급식일 | `20260708` |
| `MMEAL_SC_CODE` | 끼니 코드 | `2` |
| `MMEAL_SC_NM` | 끼니 이름 | `중식` |
| `MLSV_FGR` | 급식 인원 수 | `582.0` |
| `DDISH_NM` | **요리명** | `통밀밥 (6)<br/>순두부찌개 (1.5.9.13)<br/>사과 <br/>우유 (2)` |
| `CAL_INFO` | **열량** | `697.5 Kcal` |
| `NTR_INFO` | **영양정보** | `탄수화물(g) : 87.3<br/>단백질(g) : 40.4<br/>…` |
| `ORPLC_INFO` | **원산지** | `쌀 : 국내산<br/>배추 : 국내산<br/>…` |
| `LOAD_DTM` | 자료 갱신일 | `20260715` |

### 예시
```
https://open.neis.go.kr/hub/mealServiceDietInfo?Type=json&ATPT_OFCDC_SC_CODE=S10&SD_SCHUL_CODE=9010114&MLSV_YMD=20260708
```

## 4. 응답 구조 (여기서 많이 헤맵니다!)

### 자료가 있을 때 — 껍데기가 **두 겹**
```json
{
  "mealServiceDietInfo": [
    { "head": [ { "list_total_count": 1 },
                { "RESULT": { "CODE": "INFO-000", "MESSAGE": "정상 처리되었습니다." } } ] },
    { "row":  [ { "SCHUL_NM": "…", "DDISH_NM": "…" } ] }
  ]
}
```

```js
const rows = data.mealServiceDietInfo[1].row;        // ← 실제 자료
const total = data.mealServiceDietInfo[0].head[0].list_total_count;
```

### 자료가 없을 때 — 껍데기가 **아예 없음** ⚠️
```json
{ "RESULT": { "CODE": "INFO-200", "MESSAGE": "해당하는 데이터가 없습니다." } }
```
> 그래서 코드에서 `if (data.RESULT) { ... }` 를 **먼저** 확인해야 합니다.
> 이걸 안 하면 `Cannot read properties of undefined` 오류가 납니다.

## 5. 응답 코드

| 코드 | 뜻 | 대응 |
|---|---|---|
| `INFO-000` | 정상 처리 | — |
| `INFO-200` | 해당 데이터 없음 | 오류가 아님. 빈 목록으로 처리 |
| `INFO-300` | 인증키가 유효하지 않음 | 키를 다시 확인하거나 지우기 |
| `ERROR-290` | 인증키가 없음 | `KEY` 조건 추가 |
| `ERROR-300` | 필수 값이 누락됨 | 필수 조건 확인 |
| `ERROR-333` | 요청 값 형식이 잘못됨 | 날짜는 `YYYYMMDD` 8자리 |
| `ERROR-337` | 일일 트래픽 초과 | 인증키 등록 / 다음 날 |
| `ERROR-500`~`601` | 서버 오류 | 잠시 후 재시도 |

## 7. 알레르기 유발 식품 번호

`DDISH_NM` 의 요리 이름 뒤 괄호 안 숫자입니다. (예: `순두부찌개 (1.5.9.13)`)

| 번호 | 식품 | 번호 | 식품 |
|---|---|---|---|
| 1 | 난류(계란) | 11 | 복숭아 |
| 2 | 우유 | 12 | 토마토 |
| 3 | 메밀 | 13 | 아황산류 |
| 4 | 땅콩 | 14 | 호두 |
| 5 | 대두(콩) | 15 | 닭고기 |
| 6 | 밀 | 16 | 쇠고기 |
| 7 | 고등어 | 17 | 오징어 |
| 8 | 게 | 18 | 조개류(굴·전복·홍합 등) |
| 9 | 새우 | 19 | 잣 |

> 교육청·학교에 따라 표기 방식이 조금 다를 수 있습니다(`(1.5.9)` / `(1,5,9)` / 표시 없음 등).

## 8. 요리명에 붙는 학교별 표시

| 표시 | 대체로 이런 뜻 | 앱 처리 |
|---|---|---|
| `*요리명` | 학교가 강조 표시한 것 | `*` 제거 |
| `요리명(자)` | 자가(직접) 조리 | 제거 |
| `요리명(완)` | 완제품 사용 | 제거 |
| `요리명(과)` | 과일류 표시 | 제거 |

> 학교마다 규칙이 달라 **표준이 아닙니다.** 앱은 알레르기 번호가 아닌 짧은 괄호를 지웁니다.

## 9. 다른 NEIS 서비스 (확장 과제용)

같은 방식으로 부를 수 있습니다. **주소의 서비스 이름만 바꾸면 됩니다.**

| 서비스 이름 | 내용 |
|---|---|
| `SchoolSchedule` | 학사일정 (방학·시험·행사) |
| `hisTimetable` | 고등학교 시간표 |
| `misTimetable` | 중학교 시간표 |
| `elsTimetable` | 초등학교 시간표 |
| `classInfo` | 학급 정보 |
| `schoolMajorinfo` | 학과 정보 |
| `acaInsTiInfo` | 학원·교습소 정보 |

> 💡 **학사일정(`SchoolSchedule`)을 함께 쓰면** 방학·휴업일을 미리 알 수 있어
> "왜 급식 자료가 없지?" 문제를 프로그램이 스스로 설명할 수 있습니다. 아주 좋은 확장 과제!
