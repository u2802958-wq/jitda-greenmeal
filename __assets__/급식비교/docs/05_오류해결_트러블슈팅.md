| # | 증상 | 원인 | 해결 |

## 1. 실행·화면 문제

### ❌ `index.html`을 두 번 클릭해도 안 열린다
- 메모장이나 VS Code로 열린 경우 → **오른쪽 클릭 → 연결 프로그램 → Chrome/Edge**
- 브라우저를 **기본 프로그램**으로 지정해 두면 편합니다.

### ❌ 화면이 새까맣거나(또는 하얗고) 글자만 보인다 — 꾸미기가 안 됨
- `style.css` 파일이 `index.html` **같은 폴더**에 있는지 확인
- 파일 이름 확인: `style.css` (O) / `style.css.txt` (X) ← 메모장 저장 시 자주 생기는 실수!
  → 윈도우 탐색기 → 보기 → **파일 확장명** 체크하고 확인

### ❌ 화면은 나오는데 아무 버튼도 안 먹는다
1. `F12` → `Console` 탭 → 빨간 글씨가 있나?
2. `app.js` 맨 끝에 **`init();`** 이 있는지 확인 (가장 흔한 원인!)
3. `index.html` 맨 아래 `<script src="app.js" defer></script>` 가 있는지 확인
4. `app.js` 파일 이름이 정확한지 확인 (`App.js`, `app.JS` 는 서버에서 다른 파일로 취급될 수 있음)

### ❌ 한글이 `ë°ìì¹`처럼 깨진다
- 파일을 **UTF-8**로 저장해야 합니다.
- 메모장: `다른 이름으로 저장` → 인코딩을 **UTF-8**로 선택
- VS Code: 오른쪽 아래 인코딩 표시 클릭 → `UTF-8로 다시 저장`

## 2. 자바스크립트 오류 (F12 → Console 의 빨간 글씨)

> **F12 를 누르는 습관을 처음부터 들이세요.** 오류 메시지에 답이 적혀 있습니다.

| 오류 메시지 | 뜻 | 원인과 해결 |
|---|---|---|
| `Uncaught SyntaxError: Unexpected token` | 문법이 틀렸다 | 괄호 `)` `}` 짝, 쉼표, 따옴표 짝 확인. 오류 줄 번호 **바로 위**를 보세요 |
| `Uncaught SyntaxError: missing ) after argument list` | 닫는 괄호 빠짐 | 함수 끝 `)` 확인 |
| `Cannot read properties of null (reading 'value')` | 찾는 요소가 없다 | `$('#date')` 의 id 오타. `index.html` 의 id와 **글자 하나까지** 같아야 함 |
| `Cannot read properties of undefined (reading 'row')` | 응답 구조가 예상과 다르다 | 자료 없음(`INFO-200`)을 처리하는 `if (data.RESULT)` 를 빠뜨림 |
| `xxx is not defined` | 그런 이름이 없다 | 함수/변수 이름 오타. 또는 **아래에서 만든 것을 위에서 썼다** |
| `xxx is not a function` | 함수가 아니다 | 이름은 있는데 종류가 다름. `const`로 만든 값을 함수처럼 부른 경우 |
| `await is only valid in async functions` | `async`를 안 붙였다 | `await`를 쓰는 함수 앞에 **`async`** 추가 |
| `Assignment to constant variable` | `const`는 바꿀 수 없다 | 값을 바꿔야 하면 `let` 으로 |
| `Identifier 'x' has already been declared` | 같은 이름을 두 번 만들었다 | 단계별 코드를 붙일 때 중복 붙여넣기 한 경우. 아래 참고 ⬇️ |

### 🔁 단계 코드를 붙였는데 `already been declared` 가 뜬다
`steps/N단계_app.js` 는 **전체 파일**입니다. **덧붙이지 말고 완전히 교체**하세요.
`app.js`에서 `Ctrl+A`(전체 선택) → `Ctrl+V`(붙여넣기)

## 3. 네트워크 / API 문제

### ❌ "NEIS에 연결하지 못했습니다"
순서대로 확인하세요.

1. **인터넷이 되는지** — 다른 사이트가 열리나요?
2. **NEIS가 열리는지** — 브라우저 주소창에 아래를 붙여넣어 자료가 나오나요?
   ```
   https://open.neis.go.kr/hub/schoolInfo?Type=json&pSize=5&SCHUL_NM=창원고등학교
   ```
   - 자료가 **나온다** → 앱 코드 문제 (`F12` Console 확인)
   - 자료가 **안 나온다** → **학교 방화벽**이 막는 중
3. 방화벽이라면
   - 교육청 정보 담당 선생님께 `open.neis.go.kr` 허용 요청
   - 즉시 해결책: 휴대폰 **핫스팟**
   - 그래도 안 되면 → **`🎬 예시 데이터로 먼저 보기`** 로 수업 진행 (모든 기능이 작동합니다)

### ❌ `INFO-300 : 인증키가 유효하지 않습니다`
- 키를 붙여넣을 때 **앞뒤 공백이나 줄바꿈**이 섞였을 수 있습니다.
- `🔑` 상자에서 **지우기**를 눌러 키 없이 써 보세요 (급식 조회는 정상 작동).
- 그래도 안 되면 NEIS 포털에서 키를 다시 확인/재발급.

### ❌ `ERROR-337 : 일일 트래픽 초과`
- 키 없이 여러 명이 같은 학교 IP에서 쓰면 발생할 수 있습니다.
- **인증키를 등록**하면 한도가 크게 늘어납니다.
- 급하면: 반을 나눠 시간차로 실습하거나, 예시 데이터 모드로 진행.

### ❌ CORS 오류 (`blocked by CORS policy`)
NEIS는 `Access-Control-Allow-Origin: *` 를 보내주므로 **정상 상황에서는 나지 않습니다.**
이 오류가 나면 학교 네트워크의 **보안 장비가 응답을 가로채고 있을 가능성**이 큽니다.
→ 핫스팟 또는 예시 데이터 모드로 진행하고, 정보 담당 선생님께 문의하세요.

## 4. 데이터 문제

### ❌ 급식은 나오는데 영양소가 비어 있다
학교가 `NTR_INFO`를 등록하지 않은 경우입니다. **앱 오류가 아닙니다.**
- 앱은 `자료 없음` 으로 표시하고, 그 항목은 점수 계산에서 **자동으로 제외**합니다.
- 다른 학교로 바꾸면 대부분 나옵니다.
- 💡 **좋은 수업 소재**: "왜 어떤 학교는 영양 정보를 안 올릴까?" → 공공데이터의 품질 문제

### ❌ 열량이 1000kcal이 넘어서 점수가 너무 낮게 나온다
실제로 그런 날이 있습니다(특식·행사식·후식 추가). **버그가 아닙니다.**
- 이런 날을 찾아 "왜 높을까?" 를 분석하는 것이 오히려 좋은 활동입니다.
- 점수 계산의 `250` 값을 `150` 으로 바꾸면 감점이 완만해집니다.

### ❌ 식품군 분류가 이상하다
**의도된 한계입니다.** 컴퓨터는 요리의 뜻을 모르고 글자만 봅니다.
- 예: `리코타과일샐러드` → `리코타` 때문에 유제품으로 분류됨
- 예: `단호박크림스프` → 국물인데 채소류로 분류됨
- → 4단계 **오분류 찾기 미션**의 재료로 쓰세요! `FOOD_GROUPS` 의 낱말을 고치면 됩니다.

### ❌ 두 학교의 학교급이 달라 기준선이 안 나온다
정상입니다. 초등과 고등은 권장 열량이 다르므로(634 vs 900) 하나의 기준선을 그릴 수 없습니다.
- 같은 학교급끼리 비교하거나
- 상단 `영양 기준` 을 특정 학교급으로 **고정**하면 기준선이 나타납니다.

### ❌ 조식/석식을 골랐는데 자료가 없다
조식·석식을 하지 않는 학교가 대부분입니다. **중식**으로 바꾸세요.

## 5. 편집기 / 환경

### 📝 메모장으로도 되나요?
됩니다. 단, 이런 점을 주의하세요.
- 저장할 때 인코딩 **UTF-8**
- 파일 형식을 **모든 파일(\*.\*)** 로 바꿔야 `.txt`가 안 붙습니다
- 줄 번호가 없어서 오류 위치 찾기가 어렵습니다

### 💙 VS Code 권장 이유
- 줄 번호 표시 → 오류 줄을 바로 찾음
- 괄호 짝 색깔 표시 → 문법 오류 예방
- 저장하면 자동 UTF-8
- 오타에 빨간 밑줄

### 🌐 Live Server 확장 (선택)
꼭 필요하지 않지만(파일 두 번 클릭으로 충분) 쓰면 저장할 때마다 자동 새로고침됩니다.
VS Code → 확장 → `Live Server` 설치 → `index.html` 우클릭 → `Open with Live Server`

## 6. 수업 운영 문제

### 😰 학생 진도가 너무 벌어진다
`steps/` 폴더의 완성 코드를 **주저 없이 배포**하세요.
- 목표는 "혼자 다 타이핑하기"가 아니라 **"코드가 무엇을 하는지 이해하기"** 입니다.
- 빠른 학생에게는 워크북의 **도전 과제**를, 느린 학생에게는 **오분류 찾기·활동지**를 주면
  모두가 의미 있는 활동을 하게 됩니다.

### 😰 시간이 부족하다
`docs/01_교사용_수업지도안.md` 의 **압축 운영안(2차시 / 3차시)** 을 사용하세요.

### 😰 학생이 실명 학교를 두고 "여기 급식 별로네" 라고 말한다
**이 순간이 이 수업에서 가장 중요한 교육의 기회입니다.**
1. 앱 상단 경고문을 함께 소리내어 읽습니다.
2. "이 점수는 우리가 만든 기준이다. 슬라이더를 바꾸면 결과가 바뀐다"를 직접 보여 줍니다.
3. "데이터로는 알 수 없는 것"(급식비, 조리 인력, 잔반량, 학생 기호도)을 함께 나열합니다.
4. 활동지 **Q11, Q12** 로 연결합니다.
