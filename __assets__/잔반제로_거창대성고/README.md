# 대성 잔반 예보

거창대성고등학교의 2023~2025년 급식 메뉴(NEIS)와 잔반량 기록 2,590끼를 이용해
**오늘 급식에서 잔반이 얼마나 나올지 미리 알려 주고**, 잔반을 줄여 **탄소 배출을 줄이도록** 돕는 학교용 웹앱입니다.
PC, 태블릿, 휴대폰에서 모두 쓸 수 있습니다.

---

## 바로 쓰기

1. `index.html`을 **두 번 클릭**하면 브라우저(크롬·엣지·웨일)에서 열립니다. 설치할 것은 없습니다.
2. `index.html`, `style.css`, `app.js`, `data.js` 네 파일은 **항상 같은 폴더에** 두세요.
3. 인터넷이 연결되어 있으면 오늘 식단을 NEIS에서 실시간으로 가져옵니다.
   인터넷이 막혀 있어도 2023~2025년 기록과 앱에 저장된 2026년 1~11월 식단은 그대로 보입니다.

### 휴대폰에서 보려면
폴더를 웹에 올려 주소를 만들면 학생·교사가 휴대폰으로 바로 볼 수 있습니다.
- 학교 홈페이지 게시판이나 자료실에 올릴 수 있으면 가장 간단합니다.
- GitHub Pages, Netlify Drop(폴더를 끌어다 놓기만 하면 주소가 생김) 같은 무료 호스팅도 됩니다.

## 화면별 기능

| 화면 | 이렇게 쓰세요 |
|---|---|
| **오늘 예보** | 끼니별 예상 잔반(kg)과 단계(좋음·보통·나쁨·매우나쁨), 탄소·손실 비용, ‘오늘의 실천’ 문구. 메뉴 옆 **▲ 잔반 주의 / ▼ 잘 먹음** 표시. 카드 아래에서 **실제 잔반(L)을 바로 입력** |
| **주간 예보** | 한 주 21끼의 예상 잔반을 한눈에. 이번 주 ‘잔반 주의 메뉴’와 ‘인기 메뉴’ 목록 → 학급 조회·방송 안내에 활용 |
| **요일 분석** | 요일×끼니 히트맵, 요일별 하루 잔반, 연도별 월별 추이, **요일별로 자주 나온 메뉴와 잔반이 많았던 끼니** |
| **메뉴 분석** | 메뉴별 **잔반 지수** 순위(많이 남은 메뉴 / 잘 먹은 메뉴), 분류별 비교, 메뉴를 누르면 제공 이력과 대체 메뉴 |
| **식단 짜보기** | 메뉴를 넣고 빼며 예상 잔반 비교. 잔반이 많았던 메뉴에는 같은 분류에서 잘 먹은 메뉴를 추천(누르면 교체) |
| **탄소·기록** | 연도별 잔반·탄소·비용·소나무 환산, 월별 잔반, “○% 줄이면” 계산기, **잔반 기록 입력과 목표 달성도**, CSV 저장/가져오기, 계산 기준 변경 |
| **전광판** (오른쪽 위 버튼) | 급식실 TV·모니터에 크게 띄우는 화면. 시간에 맞춰 조식→중식→석식이 자동으로 바뀌고 30초마다 새로 고침. `Esc`로 닫기 |

## 숫자는 이렇게 계산합니다

- **원자료**: 끼니별 음식물 폐기물 발생량(L). 1L = 0.9kg으로 환산(탄소·기록 화면에서 바꿀 수 있음).
- **이상값**: 25L 이상인 5건(예: 2025-12-05 중식 161L)은 평균과 학습에서 뺐습니다.
- **예보 모델**: 끼니×요일, 월, 급식 인원, 연도와 메뉴를 함께 넣은 회귀 모델입니다.
  처음 보는 끼니에 대한 평균 오차는 **약 ±1.3kg**(교차 검증)입니다.
  분석해 보니 잔반량은 **요일·끼니·계절(월)·급식 인원**의 영향이 크고, 메뉴 하나의 영향은 대체로 0.5kg 안쪽이었습니다.
  그래서 메뉴별 효과는 참고용으로 보는 것이 좋습니다.
- **예보 단계**: 같은 달·요일·끼니의 평소 잔반과 비교해 하위 30%는 좋음, ~65% 보통, ~88% 나쁨, 그 위는 매우나쁨.
- **잔반 지수**: 그 메뉴가 나온 날 끼니 잔반이 평소(요일·끼니·월·인원 고려)보다 몇 kg 많았는지의 평균. 제공 횟수가 적으면 0 쪽으로 보정합니다. 잔반은 끼니 전체 무게로만 재었으므로 메뉴 하나를 직접 잰 값은 아닙니다.
- **탄소**: 2.5 kgCO₂e/kg (FAO 2013, 음식물 낭비의 생산~폐기 전 과정 배출량 기준). **소나무**: 30년생 소나무 1그루 연간 흡수량 6.6kgCO₂. **손실 비용**: 3,000원/kg(식재료비+처리비 추정). 모두 앱에서 바꿀 수 있습니다.

## 잔반 기록과 백업

- 오늘 예보 카드나 탄소·기록 화면에서 입력한 기록은 **그 기기의 브라우저에 저장**됩니다.
  (다른 PC나 휴대폰과 자동으로 공유되지 않고, 브라우저 기록을 지우면 사라집니다.)
- **CSV 파일로 저장**을 누르면 원본 `data.csv`와 같은 열 순서의 파일이 생깁니다. 정기적으로 저장해 두세요.
- 다른 기기에서는 **CSV 가져오기**로 기록을 옮길 수 있습니다.

## 자료 갱신 (1년에 한두 번)

새 잔반 기록을 `data.csv`에 이어 붙인 다음, 이 폴더에서 아래 명령을 실행하면
없는 날짜의 메뉴를 NEIS에서 받아 오고 모델을 다시 학습해 `data.js`를 새로 만듭니다.

```bash
pip install numpy
python tools/update_data.py ../data.csv
```

## 폴더 구성

```
잔반제로_거창대성고/
├─ index.html     ← 두 번 클릭해서 여는 파일
├─ style.css      ← 화면 디자인
├─ app.js         ← 예보 계산·차트·기록 기능
├─ data.js        ← 2023~2025 메뉴+잔반 기록, 2026 식단, 모델 계수 (update_data.py가 생성)
└─ tools/         ← 자료 갱신 도구 (update_data.py, NEIS 메뉴 캐시)
```
